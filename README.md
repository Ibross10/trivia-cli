# Trivia CLI Game

## Description
The Trivia CLI is a command-line quiz game built using JavaScript and Node.js. It allows users to answer multiple-choice questions, receive immediate feedback, and view their final score.

## Features
- 10 multiple-choice trivia questions.
- A 60-second countdown timer.
- Immediate feedback for correct and incorrect answers.
- Input validation for answers A, B, C, and D.
- Option to quit the game by entering Q.
- Score tracking and final performance summary.
- Accuracy calculation at the end of the game.

## Technologies Used
- JavaScript
- Node.js
- Node.js Readline module
- Git and GitHub

## Requirements
- Node.js installed on your computer.
- A terminal or command-line interface.

## How to Run the Game
1. Open the project directory in your terminal.
2. Run the following command:

   `node index.js`

3. Press Enter to start the quiz.
4. Type A, B, C, or D and press Enter to answer.
5. Enter Q to quit the game.

## JavaScript Concepts Demonstrated
- Functions and loops.
- Arrays and objects.
- Array iteration methods such as `forEach()` and `filter()`.
- Asynchronous JavaScript and timers.
- User input and conditional statements.
- Score tracking and result management.
